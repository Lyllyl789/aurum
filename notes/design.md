# Aurum 设计笔记

## 分层架构

Aurum 按「底层精确 → 原语 → 领域模块」三层组织：

- **money**：以币种最小货币单位为存储基础的整数金额与舍入原语，是唯一不引入浮点误差的模块。
- **tvm**：货币时间价值原语（复利、年金、永续年金），为上层模块提供折现 / 复利能力。
- **领域模块**：capital（资本预算）、amortize（摊销）、wear（折旧）、bond（债券）、ratio（比率）、currency（多币种）在 tvm / money 之上组合。

## 数值精度策略

金融计算中的误差有两个来源：二进制浮点表示误差与算法上的抵消误差。

1. **金额用整数**：`Money` 以币种最小单位（分、日元等）存储 `Int`，加减乘标量全程整数，避免 `0.1 + 0.2 != 0.3`。
2. **估算用 Double**：利率、收益率、折现等比率与估算值使用 IEEE-754 `Double`，文档明确其为「估算」，不承诺分级精度。
3. **减少抵消误差**：年金公式在利率接近零时用 `ln_1p` / `expm1`，避免 `(1+r)^n - 1` 的灾难性抵消。
4. **失败用 Option**：所有浮点函数在输入非法或结果非有限（NaN / Inf）时返回 `None`，而非中止，调用方须显式处理。

## API 约定

- 金额：`Money` 值类型，`Money::of(minor, currency)` 构造，`add` / `sub` / `scale` / `round_to` / `format` 运算。
- 估算：`Double?` 返回，`Some(value)` 为有限估算，`None` 为非法输入或非有限结果。
- 校验：有限期函数要求 `rate > -1`、`periods >= 0`；永续年金要求正利率；比率要求分母非零。
- 求根：IRR / YTM 用二分法，单符号变化保证唯一正根，最多 256 次迭代至约 `1e-12` 相对宽度。

## 关键算法

- **IRR**：`one_sign_change` 保守拒绝多符号变化现金流；区间端点异号后二分。
- **YTM**：以「债券价格 − 市价」为目标函数，在 `[-0.999999999999, 10]` 内二分，必要时右端点翻倍扩展。
- **久期 / 凸性**：按现金流加权平均的解析式直接计算。
- **汇率换算**：`minor × rate × 10^(目标小数位 − 源小数位)` 后半向上取整到目标最小单位。
