# Aurum 十月维护申报整理稿

> 本文是申报素材初稿，提交前由项目维护者核对目标、场景和赛事要求，并据实修改定稿。

## 方向与目标

参赛方向：维护已有 MoonBit 项目。Aurum 是 MoonBit 金融计算库，已参加九月赛事；十月申报只计划提交可区分、可验证的新维护贡献。它用整数最小单位处理精确金额，用 Double 估算周期现金流，并明确无效输入和计算失败边界。

本期目标：改善大额正负现金流抵消时 NPV 的数值稳定性。普通浮点累加可能在 `1e16 + 1 - 1e16` 这类输入中丢掉小额现金流。本期在保持 API 与计算约定的前提下采用补偿求和，增加边界回归测试和可运行演示。

## 预期使用场景

1. 财务应用读取精确十进制金额，将一笔账单按权重分摊给多个部门，并校验分摊总额守恒。
2. 项目负责人比较跨期投资现金流，查看逐期折现明细，并在现金流量级悬殊、正负项抵消时获得更可靠的 NPV 合计。
3. 贷款工具生成按币种最小单位逐期舍入的还款计划，汇总本金与利息，并核对期末余额归零。

## 实现与验收

在现有 capital 模块的 NPV 计算中加入 Neumaier 补偿累加；保留输入校验和失败返回约定。验收包括常规 NPV 样例、大小相差 16 个数量级的抵消样例、格式检查、编译检查、全量测试和 CLI 演示。NPV 仍是浮点估算，不承诺十进制精确性。
